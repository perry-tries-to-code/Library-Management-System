# Library Management System (Java)

A console-based Library Management System developed using Java. This project demonstrates core programming principles and provides basic functionality for managing library operations in a structured and efficient manner.

---

## Overview

The application is designed to handle essential tasks such as adding books, viewing available records, issuing books, and returning them. It follows a menu-driven approach, allowing users to interact with the system through a simple and intuitive interface.

This project serves as a foundational implementation of real-world system design using fundamental programming concepts.

---

## Features

* Add new books to the system
* View all available books
* Issue books and update their status
* Return issued books
* Display availability status of each book
* Handle invalid inputs with appropriate messages

## How to Run

1. Clone the repository:

```
git clone https://github.com/your-username/Library-Management-System.git
```

2. Navigate to the project directory:

```
cd Library-Management-System
```

3. Compile the program:

```
javac LibraryManagement.java
```

4. Run the program:

```
java LibraryManagement
```
